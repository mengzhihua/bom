# BOM 技术方案

BOM 管理零件主数据、EBOM / MBOM / SBOM 和工程变更 ECN。制造执行不在本系统。IR 拉 BOM 与 ECN 快照，并下发展开和变更指令。

## 1. 运行位置

| 场景 | 后端 | 前端开发 |
| --- | --- | --- |
| 单机 | `8082` | `5175` |
| 与控制塔同机 | `8088` | 仍用各系统自己的前端端口 |

Open IR 请求头 `X-Api-Key`，默认 `bom.open.api-key`，控制塔种子为 `bom-open-key`。

## 2. 主链路

```text
零件发布 → EBOM / MBOM / SBOM
工程变更：草稿 → 提交 → 审批 → 实施到目标 BOM
```

## 3. 控制塔读

`GET /api/open/ir/snapshots`：

| dataType | 业务键 | 说明 |
| --- | --- | --- |
| `BOM` | `bomNo` | 状态、根零件、版本、工厂 |
| `ECN` | `ecnNo` | 状态、关联 BOM 号、标题；工厂从关联 BOM 或派生 BOM 上取 |

## 4. 控制塔写

必须带 API Key。控制塔登录模式不调用本系统。统一口 `POST /api/open/ir/actions`，专用口如下。

| 指令 | 专用口 | 作用 |
| --- | --- | --- |
| `BOM_EXPLODE` | `POST /api/open/ir/explode` | 按 `bomNo` 取最新版本展开 |
| `BOM_SUBMIT_ECN` | `/submit-ecn` | 按 `ecnNo` 提交 |
| `BOM_APPROVE_ECN` | `/approve-ecn` | 按 `ecnNo` 审批 |
| `BOM_IMPLEMENT_ECN` | `/implement-ecn` | 按 `ecnNo` 实施 |

业务键也可以放在 `bomNo` 或 `ecnNo` 字段，专用口会抄进 `targetKey`。非空幂等键按 `type|业务键|key` 缓存。

## 5. 边界

展开不改 BOM。实施 ECN 才会改结构。已批准的演示 ECN 不能和另一张变更共用同一张 MBOM，否则实施会挂在错误的结构上。控制塔不直接改零件主数据。
