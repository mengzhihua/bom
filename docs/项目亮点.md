# BOM 亮点

BOM 管零件和产品结构，把工程、制造、服务三套结构以及工程变更放在一个系统里。

1. **三种结构分开维护。** 工程 BOM、制造 BOM、服务 BOM 各自有版本，而不是挤在一张物料清单里。
2. **零件能反查、能对比、能按配置解开。** 可以看出零件被哪些结构使用，也能做版本对比和配置解析。
3. **工程变更有状态，不直接改结构。** 提交、审批通过之后才实施。实施才改到目标 BOM。
4. **控制塔按编号操作。** 按 BOM 号展开最新版本，按变更号提交、审批、实施。这些动作必须带开放密钥，登录口不会悄悄改一张变更。
5. **零件生命周期可以同步到 ERP 演示。** 提交、发布、作废、升版和同步是零件自己的动作，和结构展开分开。
